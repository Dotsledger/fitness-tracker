# Ilustraciones de ejercicios

Los SVG de esta carpeta (`<slug>/frame-1..3.svg`) proceden de
**Workout Guide** (Bryl Lim, https://github.com/bryllim/workout-guide),
que a su vez amplía la obra original de **Everkinetic**
(https://github.com/everkinetic/data).

de ejecución mediante máscara CSS (color de la interfaz). `manifest.json` es un
extracto (nombre, músculos, equipo) del manifiesto original.
